# ATC combination-product prerequisite

Before outcome evaluation, determine whether combination products are already
represented as ingredient-level records.

- If yes, use the supplied exact fifth-level ATC lookup unchanged.
- If no, decompose combination products into ingredient records before applying
  the lookup.
- If decomposition is unavailable, obtain approval for a frozen crosswalk or a
  prespecified sensitivity analysis. Do not add codes after viewing results.

Record and return:

1. Number of medication rows with valid fifth-level ATC codes.
2. Number and percentage matching the locked lookup.
3. Frequencies of unmatched C03 and C10 codes.
4. Whether combination products were expanded to ingredients.
5. Any approved deviation.
